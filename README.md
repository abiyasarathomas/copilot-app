# Co-Pilot

Your work assistant. Paste or record a meeting, a hallway chat, notes, an email thread or a screenshot, and Co-Pilot turns it into a short brief, to-dos grouped by topic, date or person, and a list of missing pieces to chase. You can also talk to it.

One codebase gives you three apps:

- **Web app** that you can install from the browser (works on any computer or phone)
- **iPhone app** and **Android app**, built from the same code with [Capacitor](https://capacitorjs.com)

## How it fits together

```
 your phone / browser                         your server (Vercel)                Claude
┌──────────────────────────┐   /api/brief   ┌──────────────────────────┐        ┌──────────┐
│ src/  (React app)        │ ─────────────▶ │ api/  + server/          │ ─────▶ │ Claude   │
│ to-dos saved on device   │ ◀───────────── │ holds your Claude API key│ ◀───── │ API      │
└──────────────────────────┘                └──────────────────────────┘        └──────────┘
```

The app never sees your Claude API key. Only the server has it.

| Folder | What's in it |
|---|---|
| `src/` | The app screens: `Capture.tsx`, `Talk.tsx`, `Board.tsx` (brief, gaps, to-dos), `native.ts` (mic, speech, reminders, screen capture) |
| `server/copilot.ts` | Everything that talks to Claude: the prompts and the model settings |
| `api/` | The four server endpoints: `brief`, `day`, `prioritize`, `chat` |
| `android/`, `ios/` | The phone app projects (generated by Capacitor) |

## What works where

| Feature | Web (computer) | Web (phone) | iPhone / Android app |
|---|---|---|---|
| Brief, to-dos, gaps, prioritize | ✓ | ✓ | ✓ |
| Talk with the mic | ✓ Chrome, Edge, Safari | ✓ mostly | ✓ native |
| Record a conversation into notes | ✓ | ✓ mostly | ✓ (stops after a pause; tap again to continue) |
| Replies read aloud | ✓ | ✓ | ✓ native |
| Capture my screen | ✓ | ✗ phones don't allow it | ✗ |
| Reminders | while Co-Pilot is open | while open | ✓ even when the app is closed |

Your captures are saved **on each device**. Syncing between your phone and computer needs sign-in and a database, which is the natural next step.

## What you need

| Thing | Why | Cost |
|---|---|---|
| [Node.js](https://nodejs.org) 22 or newer | Runs the project on your computer | Free |
| A Claude API key from [console.anthropic.com](https://console.anthropic.com) | Lets the server ask Claude | Pay per use |
| A [GitHub](https://github.com) account | Stores the code | Free |
| A [Vercel](https://vercel.com) account | Hosts the web app and server | Free tier is enough to start |
| For the iPhone app: a Mac with Xcode, and an [Apple Developer](https://developer.apple.com/programs/) account | Apple requires both to install on phones and publish | $99/year |
| For the Android app: [Android Studio](https://developer.android.com/studio), and a [Google Play](https://play.google.com/console) account to publish | Builds and publishes the app | $25 once |

Keep your API key secret: put it only in `.env` on your computer and in Vercel's settings. Never paste it into code or chat.

## 1. Run it on your computer

```bash
npm install
cp .env.example .env      # then open .env and paste your ANTHROPIC_API_KEY
npm run dev               # open the address it prints, e.g. http://localhost:5173
```

## 2. Put it online (web app)

1. Push this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project**, pick the repository, and keep the defaults.
3. In **Settings → Environment Variables** add `ANTHROPIC_API_KEY`. Also add `APP_ACCESS_CODE` with any passcode, so strangers can't use your key; then type the same code in the app's Settings panel.
4. Deploy. Open the address on your phone and choose **Add to Home Screen** (iPhone: Share menu; Android: browser menu → Install app).

## 3. Build the phone apps

Put your Vercel address in `.env` as `VITE_API_BASE` (for example `https://copilot-yourname.vercel.app`), then:

```bash
npm run android   # builds, then opens Android Studio. Press Run to try it on a phone or emulator.
npm run ios       # Mac only. Builds, then opens Xcode. Pick your team under Signing, then Run.
```

Run one of these again after every change to `src/`.

## Changing how Claude behaves

All prompts are in `server/copilot.ts`. It uses the `claude-opus-5-5` model. Each call sets an `effort` level (`low` for chat, the daily brief and ranking, so they're quick; `medium` for reading notes). Raise it for more careful answers, at the cost of speed and price. If Claude declines a request, the server automatically retries it on Anthropic's recommended fallback model.
